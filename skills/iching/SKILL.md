# 周易占卦

与八字分工：八字（bazi skill）看一个人的先天底色与人生节奏；占卦看**一件具体的事**在当下的走向。两者不混用：占卦的判断以卦为本，命盘只作背景参考。

## 流程

1. **问题要具体。** 一事一问，问清是什么事、大概什么时间范围。笼统的（"我运气怎么样"）先请用户改成具体的事；那类问题应该用 bazi skill。
2. **起卦。** 用户已经掷好（给了六爻或三枚钱的正反）就用用户的；否则跑脚本随机起卦。
   ```bash
   python3 scripts/qigua.py --lines 9,7,7,8,8,6   # 六爻自下而上：6 老阴(动) 7 少阳 8 少阴 9 老阳(动)
   python3 scripts/qigua.py --toss                 # 随机起卦
   ```
   本卦、动爻、变卦、断卦取用**以脚本输出为准**。调用方已经给出脚本输出时，不要重跑、不要改。
3. **取辞。** 按脚本「断卦取用」一行引用对应的卦辞或爻辞（朱熹变占：0 动看本卦卦辞；1 动看该动爻爻辞；2 动看两动爻、以上爻为主；3 动本卦卦辞与变卦卦辞合参；4 动看变卦两不变爻、以下爻为主；5 动看变卦唯一不变爻；6 动乾用九、坤用六、余看变卦卦辞）。
   卦辞爻辞必须是《周易》原文，记不准就只讲意思，不要编造原文。
4. **落到事情上。** 结合所问之事讲：本卦是现状，变卦是走向，取用的辞是关键提示。给出倾向（宜/不宜/待时）和把握程度，不说绝对的话。
5. **命盘背景（可选）。** 调用方附了问卦人的命盘底稿时，可用来调整建议的侧重（如底子偏软的人更要稳），但不能改变卦的判断。

## 输出

面向普通人的表达遵守 zhiming skill 的「表达规范」（大白话、公历时间、少术语）；占卦例外：卦名可以说，卦辞爻辞原文最多各引一小句，紧跟大白话解释，不大段引古文。

结构（总字数 500–800）：

```
## 一句话结论
（直接回答所问之事的倾向：宜/不宜/待时，以及把握程度）
### 这一卦在说什么
（用一个画面或比喻讲清卦象，原文最多一小句）
### 落到你的事情上
（结合所问之事具体分析，变卦代表事情的走向）
### 建议
（2–3 条可执行的建议，和需要留意的时间点）

*占卦是帮你理清思路的工具，最终决定在你自己。*
```

直接输出正文，不要开场白和过程话。
